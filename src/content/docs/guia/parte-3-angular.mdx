## 3.1 Conceptos básicos de Angular

A diferencia de Vue, un componente Angular es una **clase de TypeScript** decorada con
`@Component`, con su plantilla normalmente en un archivo aparte:

```ts title="ejemplo — no forma parte del proyecto, solo ilustra el concepto"
import { Component } from '@angular/core';

@Component({
  selector: 'app-ejemplo',
  standalone: true,
  templateUrl: './ejemplo.component.html',
})
export class EjemploComponent {
  contador = 0; // propiedad normal de la clase — no necesita "ref"
}
```

```html title="ejemplo.component.html"
<button (click)="contador = contador + 1">{{ contador }}</button>
```

:::note[💡 Concepto: detección de cambios]
En Vue envuelves un valor con `ref()` para hacerlo reactivo. En Angular, una propiedad normal
de la clase ya es "observable" por el framework: Angular corre su propio ciclo de **detección
de cambios** después de eventos (clicks, respuestas HTTP) y vuelve a evaluar la plantilla.
:::

:::note[💡 Concepto: `CommonModule` y `*ngFor`]

necesita en su array `imports`. `*ngFor` (y `*ngIf`, más adelante) vienen de `CommonModule` —
por eso lo importamos aquí, algo que en Vue no tiene equivalente porque `v-for` es parte del
lenguaje de plantillas desde el principio.

## 3.5 Reemplaza el array fijo por una llamada real a la API

Con el backend de la [Parte 1](/guia/parte-1-backend/) corriendo, primero habilita
`HttpClient` en la configuración de la app:

```ts title="src/app/app.config.ts"
import { ApplicationConfig, provideZoneChangeDetection } from '@angular/core';
import { provideHttpClient } from '@angular/common/http';

export const appConfig: ApplicationConfig = {
  providers: [provideZoneChangeDetection({ eventCoalescing: true }), provideHttpClient()]
};
```

Los tipos:

```ts title="src/app/models/pedido.ts"
export interface Cliente {
  nombre: string;
  email: string;
}

export interface Pedido {
  id?: number | null;
  fecha: string;
  total: number;
  cliente: Cliente;
}
```

Un servicio que aísla la llamada HTTP. `HttpClient` devuelve **Observables** (RxJS); usamos
`firstValueFrom` para poder seguir escribiendo `async/await`, igual que en la versión Vue:

```ts title="src/app/services/pedido.service.ts"
import { Injectable } from '@angular/core';
import { HttpClient } from '@angular/common/http';
import { firstValueFrom } from 'rxjs';
import type { Pedido } from '../models/pedido';

const API_URL = 'http://localhost:5000/api/pedidos';

@Injectable({ providedIn: 'root' })
export class PedidoService {
  constructor(private http: HttpClient) {}

  obtenerTodos(): Promise<Pedido[]> {
    return firstValueFrom(this.http.get<Pedido[]>(API_URL));
  }
}
```

Y en el componente, reemplaza el array fijo por una llamada a ese servicio cuando el
componente se inicializa:

```ts title="src/app/app.component.ts"
import { Component, OnInit } from '@angular/core';
import { CommonModule } from '@angular/common';
import { PedidoService } from './services/pedido.service';
import type { Pedido } from './models/pedido';

@Component({
  selector: 'app-root',
  standalone: true,
  imports: [CommonModule],
  templateUrl: './app.component.html',
})
export class AppComponent implements OnInit {
  pedidos: Pedido[] = [];

  constructor(private pedidoService: PedidoService) {}

  async ngOnInit() {
    this.pedidos = await this.pedidoService.obtenerTodos();
    console.log('Pedidos recibidos del backend:', this.pedidos);
  }
}
```

## 3.6 Crea el primer pedido de verdad

Agrega `FormsModule` para poder usar `[(ngModel)]` (el equivalente de `v-model` en Angular),
y el método `crear` en el servicio:

```ts title="src/app/services/pedido.service.ts (agregar dentro de la clase)"
crear(pedido: Pedido): Promise<Pedido> {
  return firstValueFrom(this.http.post<Pedido>(API_URL, pedido));
}
```

```ts title="src/app/app.component.ts"
import { Component, OnInit } from '@angular/core';
import { CommonModule } from '@angular/common';
import { FormsModule } from '@angular/forms';
import { PedidoService } from './services/pedido.service';
import type { Pedido } from './models/pedido';

@Component({
  selector: 'app-root',
  standalone: true,
  imports: [CommonModule, FormsModule],
  templateUrl: './app.component.html',
})
export class AppComponent implements OnInit {
  pedidos: Pedido[] = [];
  formulario: Pedido = {
    fecha: new Date().toISOString().slice(0, 16),
    total: 0,
    cliente: { nombre: '', email: '' },
  };

  constructor(private pedidoService: PedidoService) {}

  async ngOnInit() {
    await this.cargarPedidos();
  }

  async cargarPedidos() {
    this.pedidos = await this.pedidoService.obtenerTodos();
  }

  async guardarPedido() {
    await this.pedidoService.crear({ ...this.formulario });
    await this.cargarPedidos();
  }
}
```

## 3.7 Editar y eliminar

Agrega `actualizar` y `eliminar` al servicio:

```ts title="src/app/services/pedido.service.ts (agregar)"
actualizar(id: number, pedido: Pedido): Promise<void> {
  return firstValueFrom(this.http.put<void>(`${API_URL}/${id}`, pedido));
}
eliminar(id: number): Promise<void> {
  return firstValueFrom(this.http.delete<void>(`${API_URL}/${id}`));
}
```

Ahora el componente necesita distinguir "modo crear" de "modo editar" según si `formulario.id`
tiene valor, y un método `editar` que precarga el formulario:

```ts title="src/app/app.component.ts (reemplaza todo el archivo)"
import { Component, OnInit } from '@angular/core';
import { CommonModule } from '@angular/common';
import { FormsModule } from '@angular/forms';
import { PedidoService } from './services/pedido.service';
import type { Pedido } from './models/pedido';

const vacio = (): Pedido => ({
  fecha: new Date().toISOString().slice(0, 16),
  total: 0,
  cliente: { nombre: '', email: '' },
});

@Component({
  selector: 'app-root',
  standalone: true,
  imports: [CommonModule, FormsModule],
  templateUrl: './app.component.html',
})
export class AppComponent implements OnInit {
  pedidos: Pedido[] = [];
  formulario: Pedido = vacio();

  constructor(private pedidoService: PedidoService) {}

  async ngOnInit() {
    await this.cargarPedidos();
  }

  async cargarPedidos() {
    this.pedidos = await this.pedidoService.obtenerTodos();
  }

  async guardarPedido() {
    if (this.formulario.id) {
      await this.pedidoService.actualizar(this.formulario.id, this.formulario);
    } else {
      await this.pedidoService.crear({ ...this.formulario });
    }
    this.formulario = vacio();
    await this.cargarPedidos();
  }

  editar(pedido: Pedido) {
    this.formulario = { ...pedido, cliente: { ...pedido.cliente } };
  }

  cancelar() {
    this.formulario = vacio();
  }

  async eliminar(id: number) {
    if (confirm(`¿Eliminar el pedido #${id}?`)) {
      await this.pedidoService.eliminar(id);
      await this.cargarPedidos();
    }
  }
}
```

## 3.8 Dale formato final: fechas y moneda legibles

Reemplaza la tabla completa para formatear fecha y total con `Intl`, igual que hiciste (o
harías) en Vue:

```html title="src/app/app.component.html (reemplaza la tabla)"
<table *ngIf="pedidos.length > 0" class="w-full text-left">
  <thead>
    <tr class="bg-gray-100 text-gray-700 uppercase text-xs font-semibold">
      <th class="py-3 px-4">ID</th>
      <th class="py-3 px-4">Fecha</th>
      <th class="py-3 px-4">Cliente</th>
      <th class="py-3 px-4">Total</th>
      <th class="py-3 px-4 text-center">Acciones</th>
    </tr>
  </thead>
  <tbody class="divide-y divide-gray-200 text-sm">
    <tr *ngFor="let ped of pedidos">
      <td class="py-3 px-4 font-mono">#{{ ped.id }}</td>
      <td class="py-3 px-4">{{ formatearFecha(ped.fecha) }}</td>
      <td class="py-3 px-4">
        <div class="font-semibold">{{ ped.cliente.nombre }}</div>
        <div class="text-xs text-gray-500">{{ ped.cliente.email }}</div>
      </td>
      <td class="py-3 px-4 text-emerald-600 font-bold">{{ formatearMoneda(ped.total) }}</td>
      <td class="py-3 px-4 text-center space-x-2">
        <button (click)="editar(ped)" class="bg-amber-500 text-white px-3 py-1 rounded text-xs">Editar</button>
        <button (click)="eliminar(ped.id!)" class="bg-red-600 text-white px-3 py-1 rounded text-xs">Eliminar</button>
      </td>
    </tr>
  </tbody>
</table>
```

Y agrega los dos métodos a la clase `AppComponent`:

```ts title="src/app/app.component.ts (agregar dentro de la clase)"
formatearMoneda(val: number) {
  return new Intl.NumberFormat('es-MX', { style: 'currency', currency: 'MXN' }).format(val);
}
formatearFecha(fechaStr: string) {
  return new Date(fechaStr).toLocaleString('es-MX', { dateStyle: 'medium', timeStyle: 'short' });
}
```

:::note[💡 A diferencia de Vue: funciones en la clase, no en el `<template>`]
En Vue podías escribir la expresión `Intl` directamente dentro de `{{ }}`. En Angular, la
plantilla solo puede llamar métodos que existan en la clase del componente — no evalúa
expresiones JavaScript arbitrarias con `new` dentro del HTML. Es una pequeña diferencia de
sintaxis para el mismo resultado.
:::
